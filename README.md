# OpsPulse AI is a full-stack AI software application built with Python, streamlit, and OpenAI's API. It ingests customer support queries, classifies urgency and technical scope, extracts actionable troubleshooting steps, and drafts high-quality responses for support teams.

## Features
- **Automated Categorization& Priority Scoring: ** Identifies issue types (Bugs, Billing, Features Requests) and assigns priority matrix levels.
- **Sentiment Detection: ** Gauges user frustration levels to prioritize high-risk contacts.
- **Actionable item Extraction: ** Generates internal technical steps for resolution.
- **Smart Response Generation: ** Formulates clear, professional draft replies ready for agent approval.
